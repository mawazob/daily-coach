# Daily Coach

A small web app that predicts whether you'll hit your daily step goal from your sleep, water and step count, then gives short coaching advice.

Built with plain HTML and JavaScript. The prediction logic runs in the browser, so there is no server.

## Run it
Open index.html in a browser, or use VS Code's Live Server extension.
